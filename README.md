# SaturnTsen's github io

Link: [https://saturntsen.github.io/](https://saturntsen.github.io/)

The Site is generated using [vuepress](https://vuepress.vuejs.org/) and [vuepress-theme-plume](https://github.com/pengzhanbo/vuepress-theme-plume)

## Documents

- [vuepress](https://vuepress.vuejs.org/)
- [vuepress-theme-plume](https://theme-plume.vuejs.press/)


## Usage

Install dependencies:

Requires Node.js >=22.12.0 and pnpm 9.15.0.

```sh
pnpm i
```

Start the development server:

```sh
pnpm docs:dev # start dev server
pnpm vp-update # update vuepress and theme
```

Static files will be automatically generated by github actions and pushed to the `gh-pages` branch.

## 如何撰写笔记

### 在类内添加文章

1. 在 `docs/notes/<分类>/` 中添加 Markdown 文件，设置 `title` 和 `permalink`。
2. `docs/.vuepress/collections/<分类>.ts` 使用 `sidebar: 'auto'` 时自动收录；手动侧边栏则更新对应的 `sidebar` 数组。

### 添加类

1. 在 `docs/notes/` 中新建分类文件夹及 `README.md`，设置首页的 `permalink`。
2. 在 `docs/.vuepress/collections/` 新建配置，使用 `defineCollection({ type: 'doc', title: '分类名称', dir: 'notes/<分类>', linkPrefix: '/notes/<分类>/', sidebar: 'auto' })`。
3. 在 `docs/.vuepress/collections.ts` 中导入该配置并加入 `defineCollections` 数组。
4. 在 `docs/.vuepress/plume.config.ts` 的 `navbar` 中添加导航；首页卡片在 `docs/README.md` 的 `config` 中配置。

配置参考：[Plume 集合](https://theme-plume.vuejs.press/config/collections/)、[首页区块](https://theme-plume.vuejs.press/guide/custom-home/)。

## How to Write a Blog

### Add an Article

1. Directly add a `.md` file in the `docs` folder or in a subdirectory
2. Change the permalink as needed

## How to Write Notes

### Add an Article within a Class

1. Add a Markdown file under `docs/notes/<category>/` and set its `title` and `permalink`.
2. Categories using `sidebar: 'auto'` include it automatically. Otherwise, update the `sidebar` array in `docs/.vuepress/collections/<category>.ts`.

### Add a Class

1. Create `docs/notes/<category>/README.md` and set its `permalink`.
2. Add a `defineCollection` configuration in `docs/.vuepress/collections/` with `type: 'doc'`, a `title`, `dir: 'notes/<category>'`, `linkPrefix: '/notes/<category>/'`, and `sidebar`.
3. Register it in `docs/.vuepress/collections.ts`.
4. Add navigation in `docs/.vuepress/plume.config.ts` and an optional homepage card in `docs/README.md`.


## Deploy to GitHub Pages

The site deploys through GitHub Actions: `.github/workflows/deploy.yml`. You also need to make the following settings in the GitHub repository:

- [ ] `settings > Actions > General`, Scroll to the bottom of the page, under `Workflow permissions`, check `Read and write permissions`, and click the save button.

- [ ] `settings > Pages`, In `Build and deployment`, select `Deploy from a branch` for `Source`, choose `gh-pages` for `Branch`, and click the save button.
  (The `gh-pages` branch may not exist upon first creation. You can complete the above setup first, push the code to the main branch, wait for `github actions` to finish, and then proceed with the setup.)

- [ ] Modify the `base` option in `docs/.vuepress/config.ts`:
  - If you are planning to deploy to `https://<USERNAME>.github.io/`, you can skip this step as `base` defaults to `"/"`.
  - If you are planning to deploy to `https://<USERNAME>.github.io/<REPO>/`, meaning your repository URL is `https://github.com/<USERNAME>/<REPO>`, set `base` to `"/<REPO>/"`.

To customize a domain name, please refer to [Github Pages](https://docs.github.com/zh/pages/configuring-a-custom-domain-for-your-github-pages-site/about-custom-domains-and-github-pages)
