理论篇

1. 前向扩散：离散与连续的桥梁

前向扩散过程的核心思想是逐步、可控地向数据中添加高斯噪声，直到数据完全变成一个标准的先验高斯分布。

1.1 离散前向马尔可夫链（DDPM Forward）

DDPM采用马尔可夫链的形式，每一步只依赖于前一步的状态：

q(xt∣xt−1)=N(xt;αtxt−1,(1−αt)I)q(x_t \mid x_{t-1}) = \mathcal{N}(x_t; \sqrt{\alpha_t}x_{t-1}, (1 - \alpha_t)I) q(xt​∣xt−1​)=N(xt​;αt​​xt−1​,(1−αt​)I)

这一步操作相当于将 xt−1x_{t-1}xt−1​ 乘以 αt\sqrt{\alpha_t}αt​​（保留信号），然后加上一个方差为 (1−αt)I(1-\alpha_t)I(1−αt​)I 的高斯噪声。

由于高斯分布的线性叠加特性，我们可以得到一个从 x0x_0x0​ 直接到 xtx_txt​ 的闭式边缘分布：

xt=αˉtx0+1−αˉtε,ε∼N(0,I)(F-closed)x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1 - \bar\alpha_t}\varepsilon, \quad \varepsilon \sim \mathcal{N}(0, I) \tag{F-closed} xt​=αˉt​​x0​+1−αˉt​​ε,ε∼N(0,I)(F-closed)

这个公式是DDPM训练的基础。它表明 xtx_txt​ 可以看作是原始数据 x0x_0x0​（被 αˉt\sqrt{\bar\alpha_t}αˉt​​ 衰减）和纯噪声 ε\varepsilonε（被 1−αˉt\sqrt{1 - \bar\alpha_t}1−αˉt​​ 缩放）的线性组合。这使得我们可以直接从 x0x_0x0​ 采样任意时刻 ttt 的 xtx_txt​，而无需迭代 ttt 步，极大地简化了训练过程。

可以证明，xtx_txt​ 依概率收敛至 N(0,Id)\mathcal{N}(0,I_d)N(0,Id​), 这是Diffusion模型采样的基础。

1.2 连续前向 SDE（VP-SDE 典型形态）

当离散步长趋于无穷小，DDPM过程可以被一个随机微分方程 (SDE) 描述，典型的VP-SDE（Variance Preserving SDE）形式为：

dxt=−12β(t)xtdt+β(t)dWt(VP-SDE)\mathrm{d}x_t = -\frac{1}{2}\beta(t)x_t \mathrm{d}t + \sqrt{\beta(t)}\mathrm{d}W_t \tag{VP-SDE} dxt​=−21​β(t)xt​dt+β(t)​dWt​(VP-SDE)

其中

  • dxt\mathrm{d}x_tdxt​：xxx 在极短时间 dt\mathrm{d}tdt 内的变化量。
  • −12β(t)xtdt-\frac{1}{2}\beta(t)x_t \mathrm{d}t−21​β(t)xt​dt：漂移项 (Drift)。它是一个确定性项，将 xtx_txt​ 拉向原点（均值）。这对应于离散DDPM中 αt<1\sqrt{\alpha_t} < 1αt​​<1 的信号衰减。
  • β(t)dWt\sqrt{\beta(t)}\mathrm{d}W_tβ(t)​dWt​：扩散项 (Diffusion)。它是一个随机项，dWt\mathrm{d}W_tdWt​ 是布朗运动，代表高斯噪声的注入。这对应于离散DDPM中添加的噪声。
  • （布朗运动是最常见的随机过程之一，其最重要的性质是独立增量，且增量为高斯向量 Wt−Ws∼N(0,(t−s)I)W_t - W_s\sim \mathcal{N}(0,(t-s)I)Wt​−Ws​∼N(0,(t−s)I)

SDE描述了单个样本 xtx_txt​ 的轨迹，而Fokker–Planck (Kolmogorov Forward) 方程则描述了整个概率密度函数 pt(x)p_t(x)pt​(x) 随时间 ttt 的演化：

2. 反向过程：SDE 与 ODE 的双重路径

生成过程（去噪）是前向扩散过程的逆转。根据SDE理论，反向过程的动力学可以被精确地推导出来。

2.1 反向时间 SDE（Reverse-Time SDE）

对于一般的SDE

dxt=f(xt,t)dt+g(t)dWt\mathrm{d}x_t = f(x_t, t)\mathrm{d}t + g(t)\mathrm{d}W_t dxt​=f(xt​,t)dt+g(t)dWt​

其反向过程满足：

dxt=(f(xt,t)−g(t)2∇xlog⁡pt(xt))dt+g(t)dWˉt(Reverse-SDE)\mathrm{d}x_t = \Big(f(x_t, t) - g(t)^2 \nabla_x \log p_t(x_t)\Big)\mathrm{d}t + g(t)\mathrm{d}\bar{W}_t \tag{Reverse-SDE} dxt​=(f(xt​,t)−g(t)2∇x​logpt​(xt​))dt+g(t)dWˉt​(Reverse-SDE)

  • dWˉt\mathrm{d}\bar{W}_tdWˉt​：这是反向时间的布朗运动，分布上等于布朗运动。
  • 核心项 g(t)2∇xlog⁡pt(xt)g(t)^2 \nabla_x \log p_t(x_t)g(t)2∇x​logpt​(xt​)：这是Score Function发挥作用的地方。它修正了前向的漂移项 f(xt,t)f(x_t, t)f(xt​,t)。
    • 前向过程的漂移 fff 将数据推向原点（或均值）。
    • 反向过程需要一个反向漂移来将数据从原点推回数据流形。这个反向漂移项正是由 g(t)2g(t)^2g(t)2 乘以 Score Function ∇xlog⁡pt(xt)\nabla_x \log p_t(x_t)∇x​logpt​(xt​) 构成。
    • Score Function ∇xlog⁡pt(xt)\nabla_x \log p_t(x_t)∇x​logpt​(xt​) 指向密度增大的方向，因此它指导了反向过程如何沿着概率密度最高的路径（即数据流形）进行去噪。

将VP-SDE的参数代入，得到VP-SDE的反向形式：

dxt=(−12β(t)xt−β(t)∇xlog⁡pt(xt))dt+β(t)dWˉt(VP-Reverse)\mathrm{d}x_t = \Big(-\frac{1}{2}\beta(t)x_t - \beta(t)\nabla_x \log p_t(x_t)\Big)\mathrm{d}t + \sqrt{\beta(t)}\mathrm{d}\bar{W}_t \tag{VP-Reverse} dxt​=(−21​β(t)xt​−β(t)∇x​logpt​(xt​))dt+β(t)​dWˉt​(VP-Reverse)

2.2 Probability Flow ODE（确定性版本）

我们还可以找到一个确定性的常微分方程（ODE），它与SDE共享相同的边际概率密度 pt(x)p_t(x)pt​(x)：

dxtdt=f(xt,t)−12g(t)2∇xlog⁡pt(xt)(PF-ODE)\frac{\mathrm{d}x_t}{\mathrm{d}t} = f(x_t, t) - \frac{1}{2}g(t)^2 \nabla_x \log p_t(x_t) \tag{PF-ODE} dtdxt​​=f(xt​,t)−21​g(t)2∇x​logpt​(xt​)(PF-ODE)

3. Score Matching：学习不可见的边缘 Score

有了以上方程，我们便知道了加噪和逆向过程。为了实现逆向过程，我们要估计score function。因此，我们的目标是学习一个网络sθ(t,xt)≈∇xtlog⁡pt(xt)s_\theta(t,x_t)\approx \nabla_{x_t} \log p_t(x_t)sθ​(t,xt​)≈∇xt​​logpt​(xt​). 然而 score function 依赖于边际密度 pt(⋅)p_t(\cdot)pt​(⋅)，而 pt(⋅)p_t(\cdot)pt​(⋅) 在高维空间中是不可计算的。Score Matching提供了一种绕过这一难题的方法。

3.1 关键恒等式：边缘 Score 是条件 Score 的后验期望

LtDSM(θ)=Ex0,xt[∥sθ(xt,t)−u(x0,xt)∥2]\mathcal{L}_t{\text{DSM}}(\theta) = \mathbb{E}_{x_0, x_t}\big[\|s_\theta(x_t, t) - u(x_0, x_t)\|^2\big] Lt​DSM(θ)=Ex0​,xt​​[∥sθ​(xt​,t)−u(x0​,xt​)∥2]

sθ(xt,t)=−1σtεθ(xt,t)(eps-to-score)\boxed{s_\theta(x_t, t) = -\frac{1}{\sigma_t}\varepsilon_\theta(x_t, t)} \tag{eps-to-score} sθ​(xt​,t)=−σt​1​εθ​(xt​,t)​(eps-to-score)

预测干净样本 x^0\hat{x}_0x^0​： 我们定义对原始干净样本 x^0\hat{x}_0x^0​ 的预测：

x^0=xt−σtεθ(xt,t)αˉt(x0hat)\boxed{\hat{x}_0 = \frac{x_t - \sigma_t \varepsilon_\theta(x_t, t)}{\sqrt{\bar\alpha_t}}} \tag{x0hat} x^0​=αˉt​​xt​−σt​εθ​(xt​,t)​​(x0hat)

物理意义： x^0\hat{x}_0x^0​ 是在当前 xtx_txt​ 和预测噪声 εθ\varepsilon_\thetaεθ​ 的基础上，通过解析方法得到的最可能的原始数据。在反向SDE/ODE的离散化中，x^0\hat{x}_0x^0​ 是最自然的“去噪中心”。后文离散去噪过程会用到这个值。

5. 离散去噪：DDPM 与 DDIM

现在我们将连续的反向SDE/ODE转化为实际可执行的离散更新步骤，即采样过程（Sampling）。

5.1 DDPM Sampling（随机；反向 SDE 的离散化）

DDPM采样是基于反向马尔可夫链的，它对应于反向SDE的一种离散化。

xt−1=1αt(xt−1−αt1−αˉtεθ(xt,t))+β~tz,z∼N(0,I)(DDPM-step)\boxed{x_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left( x_t - \frac{1-\alpha_t}{\sqrt{1-\bar\alpha_t}}\varepsilon_\theta(x_t, t) \right) + \sqrt{\tilde\beta_t}z, \quad z \sim \mathcal{N}(0, I)} \tag{DDPM-step} xt−1​=αt​​1​(xt​−1−αˉt​​1−αt​​εθ​(xt​,t))+β~​t​​z,z∼N(0,I)​(DDPM-step)

其中 β~t=1−αˉt−11−αˉtβt\tilde\beta_t = \frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_tβ~​t​=1−αˉt​1−αˉt−1​​βt​。

  • 均值项（去噪）：公式中 1αt(… )\frac{1}{\sqrt{\alpha_t}} (\dots)αt​​1​(…) 部分是确定性的去噪方向，它将 xtx_txt​ 沿着 Score Function 指引的方向推向 xt−1x_{t-1}xt−1​ 的均值。
  • 方差项（随机性）：β~tz\sqrt{\tilde\beta_t}zβ~​t​​z 是注入的高斯噪声。这保证了DDPM采样是随机的，每次运行都会产生不同的结果，从而覆盖整个数据分布。

5.2 DDIM Sampling（确定性；Probability Flow ODE 的离散化）

DDIM（Denoising Diffusion Implicit Models）采样是基于Probability Flow ODE的，它通常是确定性的（当 η=0\eta=0η=0 时）。DDIM通过重参数化，允许使用更少的采样步数。

xt−1=αˉt−1x^0+1−αˉt−1εθ(xt,t),x^0 由式 (x0hat) 给出(DDIM-step)\boxed{x_{t-1} = \sqrt{\bar\alpha_{t-1}}\hat{x}_0 + \sqrt{1-\bar\alpha_{t-1}}\varepsilon_\theta(x_t, t), \quad \hat{x}_0 \text{ 由式 }(x0hat) \text{ 给出}} \tag{DDIM-step} xt−1​=αˉt−1​​x^0​+1−αˉt−1​​εθ​(xt​,t),x^0​ 由式 (x0hat) 给出​(DDIM-step)

  • DDIM将 xt−1x_{t-1}xt−1​ 分解为两部分：预测的干净信号 αˉt−1x^0\sqrt{\bar\alpha_{t-1}}\hat{x}_0αˉt−1​​x^0​ 和残余噪声 1−αˉt−1εθ(xt,t)\sqrt{1-\bar\alpha_{t-1}}\varepsilon_\theta(x_t, t)1−αˉt−1​​εθ​(xt​,t)。
  • 当 η=0\eta=0η=0 时，DDIM不添加额外的随机噪声，因此它沿着一条确定性的“概率流线”进行去噪。这使得DDIM可以进行快速采样（子采样时间步）和一致性采样（相同的 xTx_TxT​ 总是得到相同的 x0x_0x0​）。

5.3. DDPM vs DDIM：同网络、不同路径、同终点

在理想条件下（Score函数真实、连续时间、无离散误差），Reverse-SDE（DDPM的理论基础）和 PF-ODE（DDIM的理论基础）都由同一个 ∇log⁡pt\nabla\log p_t∇logpt​ 驱动。它们都严格保证将先验分布 pTp_TpT​ 推回到数据分布 p0p_0p0​。即 X0SDE∼p0X_0^{\text{SDE}} \sim p_0X0SDE​∼p0​ 且 X0ODE∼p0X_0^{\text{ODE}} \sim p_0X0ODE​∼p0​。

然而，它们中间时刻的分布一般不同，即虽然起点和终点分布相同，但DDPM的随机路径和DDIM的确定性流线在中间时刻的样本分布是不同的。工程实践：同一个训练好的网络 εθ\varepsilon_\thetaεθ​ 可以同时兼容 DDPM 和 DDIM 两种采样器（Scheduler），前提是使用了一致的噪声参数项和参数化换算。

6. Scheduler 的核心功能总结

Scheduler 是连接训练好的网络 εθ\varepsilon_\thetaεθ​ 和最终采样结果的桥梁。它负责将连续的数学理论转化为离散的工程实现。给定网络输出 εθ(xt,t)\varepsilon_\theta(x_t, t)εθ​(xt​,t)，Scheduler 负责以下五个核心功能：

功能描述对应数学概念
1. 时间网格确定从 tTt_TtT​ 到 t0t_0t0​ 的离散时间序列。允许子采样（如DDIM）以加速。离散化步长 Δt\Delta tΔt 的选择。
2. 噪声日程提供每一步所需的 αt,αˉt,σt\alpha_t, \bar\alpha_t, \sigma_tαt​,αˉt​,σt​ 等参数。前向过程的参数定义。
3. 语义变换实现 εθ↔sθ↔x^0\varepsilon_\theta \leftrightarrow s_\theta \leftrightarrow \hat{x}_0εθ​↔sθ​↔x^0​ 之间的解析换算。(eps-to-score) 和 (x0hat) 公式。
4. 一步更新公式实现 DDPM-step 或 DDIM-step 等离散更新公式。反向 SDE/ODE 的数值求解器。
5. 随机性控制决定是否注入随机噪声，以及注入多少（如DDIM中的 η\etaη 参数）。Reverse-SDE 与 PF-ODE 的选择。

这个总结链条清晰地展示了扩散模型的完整理论框架： 前向 SDE → 反向 SDE（定理）→ Score Identity → DSM（Tower + 投影定理）→ 噪声参数化 → 离散更新（DDPM/DDIM）。

7. 代码

import torch
from diffusers import DDPMScheduler, UNet2DModel
from PIL import Image
import os

# --- 1. Setup and Model Loading ---
# 使用一个轻量级的预训练模型进行演示
MODEL_ID = "google/ddpm-cifar10-32"
# 确保使用GPU（如果可用）
device = "cuda" if torch.cuda.is_available() else "cpu"

print(f"Loading model and scheduler on device: {device}")

# 加载预训练的UNet模型（噪声预测网络）
unet = UNet2DModel.from_pretrained(MODEL_ID)
unet.to(device)

# 加载DDPM调度器（Scheduler），它包含了我们理论中讨论的 alpha, beta 等参数
scheduler = DDPMScheduler.from_pretrained(MODEL_ID)

# --- 2. Generation Parameters ---
# 图像尺寸和通道数
sample_size = unet.config.sample_size
batch_size = 1
# 采样步数，对应理论中的 T
scheduler.set_timesteps(num_inference_steps=1000)
timesteps = scheduler.timesteps

# --- 3. Initial Noise (x_T) ---
# 从标准高斯分布中采样初始噪声 x_T
# 对应理论中的 x_T ~ N(0, I)
latents = torch.randn(
    (batch_size, unet.config.in_channels, sample_size, sample_size)
).to(device)

print(f"Starting denoising loop with {len(timesteps)} steps...")

# --- 4. Denoising Loop (Reverse Process) ---
# 对应理论中的 DDPM-step 或 DDIM-step 的迭代过程
for i, t in enumerate(timesteps):
    # 1. 预测噪声 (Predict noise)
    # t 是一个张量，需要将其转换为模型接受的格式
    t_tensor = torch.tensor([t], device=device)
    
    # 模型 s_theta(x_t, t) 预测的是噪声 epsilon_theta(x_t, t)
    with torch.no_grad():
        noise_pred = unet(latents, t_tensor).sample

    # 2. 计算 x_{t-1} (Compute x_{t-1})
    # 调度器根据预测的噪声和当前状态，计算下一步的去噪结果
    # 这一步内部实现了 DDPM-step 的公式
    latents = scheduler.step(noise_pred, t, latents).prev_sample

    if (i + 1) % 100 == 0 or i == len(timesteps) - 1:
        print(f"Step {i+1}/{len(timesteps)} completed (t={t.item()})")

# --- 5. Post-processing and Saving ---
# 将结果从 [-1, 1] 范围缩放到 [0, 255]
latents = (latents / 2 + 0.5).clamp(0, 1)
latents = latents.cpu().permute(0, 2, 3, 1).numpy()
image = (latents[0] * 255).astype("uint8")
image = Image.fromarray(image)

OUTPUT_PATH = "generated_image.png"
image.save(OUTPUT_PATH)
print(f"\nGeneration complete. Image saved to {OUTPUT_PATH}")

# 确保文件存在以便交付
if os.path.exists(OUTPUT_PATH):
    print("File check passed.")
else:
    print("Error: Output file not found.")
